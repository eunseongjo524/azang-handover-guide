# 직원 인수인계 안내 페이지

브라우저에서 `index.html`을 열면 바로 확인할 수 있는, 별도 설치가 필요 없는 정적 웹페이지입니다.

## 구성

- 첫 화면: `홀` / `주방` 선택
- 섹션 화면: 업무 카테고리 목록
- 상세 화면: 안내 문구와 사진·냉장고 위치 도식 영역
- 어느 화면에서나 `처음으로`로 이동

화면 전환은 `app.js`의 JavaScript 렌더링으로 이루어지므로 새로고침되지 않습니다.

## 사진 및 도식 추가하기

1. 사진 또는 도식 파일을 `assets/` 폴더에 넣습니다. (폴더는 필요할 때 만들어도 됩니다.)
2. `app.js`의 해당 카테고리 `media: []`를 아래처럼 바꿉니다.

```js
media: [
  {
    src: "./assets/bat-fridge.jpg",
    alt: "바트냉장고 전체 모습",
    caption: "왼쪽부터 양파, 대파, 버섯 순서"
  },
  {
    src: "./assets/bat-fridge-map.png",
    alt: "바트냉장고 재료 보관 위치 도식",
    caption: "재료 보관 위치 도식"
  }
]
```

이미지를 누르면 크게 볼 수 있습니다. 업무 카테고리를 더 만들려면 같은 파일에서 `categories` 목록에 `{ id, title, icon, summary, note, media }` 형식의 항목을 추가하면 됩니다.
